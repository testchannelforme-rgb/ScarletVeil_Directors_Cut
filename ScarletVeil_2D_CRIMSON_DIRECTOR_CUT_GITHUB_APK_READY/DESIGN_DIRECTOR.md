# SCARLET VEIL — CRIMSON DIRECTOR CUT

## The new hook

Scarlet Veil is no longer only "a good dark-fantasy Metroidvania." Its signature mechanic is **memory as level-state and player choice**.

The first prototype of this is the **Memory Loom** in Ashen Hollow. Two contradictory memories occupy the same event. The Loom cannot identify objective truth; it asks the player which memory the world should obey. That decision is saved permanently and changes the emotional/gameplay response.

Long-term, this system is intended to evolve into:
- rooms that physically reconstruct based on believed memories;
- NPC identities that change depending on recovered contradictions;
- bosses with remembered vs forgotten move sets;
- secret routes created by choosing painful truths over comforting falsehoods;
- endings determined by which version of Cael Mourne the player helped make "real."

## Core feel pillars

1. **Movement is combat.** Jump, wall jump, dash, grapple swing, aerial attacks and Falling Thread should chain without dead time.
2. **Every hit communicates.** Slash trails, hit-stop, screen shake, recoil, sound and Thread Resonance create a readable feedback stack.
3. **Silence is content.** Not every room is a fight. Architecture, distant bells, drifting pages and Memory Shards carry story.
4. **Bosses are trapped memories.** Mother Thren, Bellkeeper and the Pale Regent each fight according to the memory they cannot release.
5. **Mobile is first-class.** 1280×720 reference viewport, canvas scaling, touch controls, Compatibility renderer, ARM64 export, modest particle/overdraw budget.

## Vertical slice structure

### Forgotten Sanctuary
Teach movement without tutorial spam. Earn Wall Jump and Scarlet Dash. Find the Echo Mask in an optional loft.

### Ashen Hollow
Introduce Hollowed civilians, Hunter Mask, Threadblade Grapple and the Memory Loom. Fight Mother Thren in Cradle Court.

### Iron Choir
Movement/combat integration intensifies. Earn Falling Thread. Bellkeeper tests parry timing, wave avoidance and spacing.

### Drowned Archive
A quieter traversal interlude: moving platforms over black water, floating pages, ranged Ink Wraiths and contradictory royal orders.

### Crimson Approach
The Pale Regent is a three-phase duel: ceremonial swordplay, Veil projectiles/teleports, then borrowed memories made physical.

### Heartwell Threshold
The Scarlet Echo speaks. Ending choices are exposed as a prototype; the secret choice requires all 12 Memory Shards + Echo Mask.
